HyperFrames

Tu décris ta vidéo à Claude, il la fabrique, et tu récupères un vrai fichier vidéo (MP4).

Comment l'utiliser

  1. 1
    Prépare ton ordinateurIl te faut Claude Code, Node.js 22 et FFmpeg. Pas sûr de les avoir ? Demande à Claude de vérifier et de t'aider à les installer.
  2. 2
    Colle ces 2 lignes dans le TerminalPuis ouvre une nouvelle conversation dans Claude Code.
    claude plugin marketplace add heygen-com/hyperframesclaude plugin install hyperframes@hyperframes
  3. 3
    Demande ta vidéoClaude te montre un aperçu, tu demandes les changements, puis il te sort le MP4. « Avec /hyperframes:hyperframes, fais-moi une vidéo de 10 secondes qui présente mon site [ton adresse]. »

À savoir avant

  • Ça marche dans Claude Code, sur ordinateur (Mac, Windows ou Linux), pas sur le téléphone.
  • Claude Code demande un compte Claude payant. HyperFrames, lui, est gratuit : seules quelques options de HeyGen (offre Pro) sont payantes, et tu n'en as pas besoin pour commencer.
  • Sans Claude Code : il existe un connecteur pour l'appli Claude, en bêta, qui passe par un compte HeyGen.

Tu veux d'autres outils comme ça ? Dans le Club, on se partage des skills entre entrepreneurs. Ce n'est pas obligatoire pour récupérer HyperFrames.
