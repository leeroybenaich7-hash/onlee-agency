Le pack 3D

13 skills qui apprennent la 3D (Three.js) à Claude Code. Gratuit, une commande à copier.

La commande à copier

$npx skills add cloudai-x/threejs-skills

À coller dans le terminal de ton ordinateur (il faut Node.js). Ensuite, Claude Code prend le bon skill tout seul quand tu lui parles de 3D.

Les 13 skills, en français

  • animation : faire bouger les objets (images clés, squelettes, mélange de mouvements).
  • fundamentals : les bases (la scène, la caméra, le rendu, la boucle d'animation).
  • shaders : écrire des effets visuels sur mesure (shaders).
  • materials : l'aspect des surfaces (mat, brillant, métal, style dessin animé).
  • geometry : créer des formes et du texte en 3D, même en très grand nombre.
  • interaction : cliquer, survoler et glisser les objets 3D, tourner autour à la souris ou au doigt.
  • postprocessing : les effets sur l'image finale (lueur, flou, profondeur de champ).
  • lighting : les lumières, les ombres et l'éclairage d'ambiance.
  • loaders : charger des modèles 3D (glTF), des textures et des décors.
  • textures : poser des images sur les objets, avec les bonnes couleurs.
  • performance : mesurer et accélérer la 3D pour qu'elle reste fluide.
  • react-three-fiber : faire la 3D dans un site React.
  • asset-pipeline : alléger les fichiers 3D pour qu'ils chargent vite.

À savoir avant

  • Ce pack s'installe dans Claude Code, avec une commande. Ce n'est pas un bouton dans l'application Claude.
  • La boîte 3D de mon site onlee.fr n'a pas été faite avec ce pack. Elle a demandé 23 versions sur une semaine. Le pack donne de meilleures bases à Claude, pas un site fini.
  • Je n'ai pas encore testé le pack moi-même : je te montre sa page et ses chiffres.
  • Il est écrit par d'autres (CloudAI-X), en anglais. Comme tout skill trouvé en ligne, jette un œil avant de l'installer.
