Comment l'utiliser

  1. 1
    Dans l'appli Claude : il y est déjàLes skills d'exemple d'Anthropic, dont frontend-design, sont déjà disponibles avec les offres payantes. Tu n'as rien à installer.
  2. 2
    Dans Claude Code : tape ces 2 commandesÀ taper dans Claude Code (pas dans le Terminal). Elles ajoutent les skills d'exemple d'Anthropic.
    /plugin marketplace add anthropics/skills/plugin install example-skills@anthropic-agent-skills
  3. 3
    Décris ton projet, avec ton sujet et tes clientsPlus tu donnes de détails sur ton métier, plus le style sera à toi. « Fais la page d'accueil de ma boulangerie à Lyon, chaleureuse, pour des familles. »

À savoir avant

  • Il faut une offre Claude payante (appli ou Claude Code).
  • C'est un guide de style : le résultat dépend de ce que tu lui racontes sur ton projet.
  • Relis toujours le site avant de le mettre en ligne : textes, prix, coordonnées.

Tu veux d'autres outils comme ça ? Dans le Club, on se partage des skills entre entrepreneurs. Ce n'est pas obligatoire pour récupérer frontend-design.
