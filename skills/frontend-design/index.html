Le kit frontend-design

Copie, colle : ton site ne fait plus « IA ».

Le prompt à coller

Utilise le skill frontend-design. Fais la page d'accueil de mon site, en une seule page. Mon activité : [ce que je fais, en une phrase] Où : [ma ville ou ma zone] Mes clients : [qui ils sont, ce qu'ils cherchent] Ce qu'ils doivent faire sur la page : [appeler, réserver, demander un devis…] Mes preuves : [années d'expérience, avis, réalisations : que du vrai] Mes coordonnées : [téléphone, adresse, horaires] Mes prix : [ce que tu affiches, ou « je ne les affiche pas »] Mes photos : [j'en ai / je n'en ai pas encore] Avant de coder, propose-moi en 5 lignes une direction de style (couleurs, police, mise en page) et dis-moi pourquoi elle colle à mon métier. Évite les signes des sites faits par l'IA : dégradés en décoration, cartes toutes identiques, un seul mot coloré dans le titre, petits titres en majuscules au-dessus de chaque bloc, flèches dans les boutons, emojis à la place des icônes. Textes courts et concrets, en français. N'invente aucun chiffre, aucun prix ni aucun avis. S'il te manque une information pour finir la page, demande-la-moi avant de coder.

Les étapes dans Claude

  1. claude.ai, Paramètres › Capacités : active « Créer et modifier des fichiers ».
  2. Personnaliser › Compétences (Skills) : active frontend-design.
  3. Nouvelle conversation : colle le prompt, remplis les [ ].
  4. Retouches en une phrase : « plus sobre ».

Tu utilises Claude Code ?

Tape ces 2 commandes dans Claude Code (pas dans le Terminal). Elles ajoutent les skills d'exemple d'Anthropic, dont frontend-design.

/plugin marketplace add anthropics/skills /plugin install example-skills@anthropic-agent-skills
Voir frontend-design sur GitHub

À savoir avant

  • D'après l'aide officielle de Claude (mise à jour du 10/11/2026), les skills sont ouverts à toutes les offres, même gratuite, si « Créer et modifier des fichiers » est activé.
  • C'est un guide de style : le résultat dépend de ce que tu racontes sur ton projet. Plus ce que tu mets entre [ ] est précis, plus le site est à toi.
  • Claude te fait la page. La mettre en ligne sur ton propre nom de domaine, c'est une autre étape.
  • Relis toujours avant de publier : textes, prix, coordonnées.
